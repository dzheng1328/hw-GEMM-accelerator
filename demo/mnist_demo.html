Phase 1 · hardware verification

MNIST, classified on simulated silicon

Eight real MNIST test digits, fed as one batch into an 8×8 output-stationary systolic array (Verilog, simulated via cocotb + Icarus). Each row of the array classifies one digit simultaneously — the matrix multiplies are tiled into repeated 8×8×8 hardware passes and the result matches a NumPy reference bit-exactly.
